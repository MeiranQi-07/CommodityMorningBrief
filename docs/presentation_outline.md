## 第2页：痛点与目标（1.5分钟）

**问题：**
- 个人投资者开盘前想了解"夜盘收盘后国际市场发生了什么"
- 手动翻新闻来不及，券商晨会需付费，信息过载
- 不同品种夜盘收盘时间不同（金银02:30、铜01:00），gap 段信息难获取

**目标：**
- 每天 08:30 自动推送开盘前简报 → 邮箱
- 覆盖黄金、白银、铜、原油等品种
- 用 LLM 替代研究员做新闻筛选和影响分析
- 带自动回测复盘，持续提升分析质量

## 第3页：整体架构（2分钟）

```
08:30 cron 触发
 ┌─ ① 新闻采集 ← 第一财经 + 财联社（窗口 02:30~08:30）
 ├─ ② LLM 筛选+分析 ← 从原始新闻中过滤商品相关，标注影响方向
 ├─ ③ 报告生成 ← 行情速览 + 新闻分析 + Excel
 ├─ ④ 推送 → 📬 邮箱
 │
 ┌─ ⑤ 回测 ← 对比昨天 LLM 判断 vs 实际行情（异步）
 ├─ ⑥ 自我复盘 ← 分析多期回测，检测偏差
 └─ ⑦ 校准注入 ← 偏差写入 prompt，下次自动修正
```

> PPT 配数据流图，箭头标出 7 步

**关键设计：** 回测复盘校准（⑤⑥⑦）放在报告推送（④）之后异步执行，不阻塞早报产出。

## 第4页：时间窗口设计——核心亮点之一（2分钟）

**为什么是 02:30~08:30？**

| 品种 | 夜盘收盘 | 分析窗口 | 设计理由 |
|---|---|---|---|
| 黄金/白银 | 02:30 | 02:30~08:30 | 夜盘收后国际现货仍在波动 |
| 原油 | 02:30 | 02:30~08:30 | WTI/布伦特 24h 电子盘 |
| 铜/基本金属 | 01:00 | 01:00~08:30 | LME 仍在交易 |

08:30 截稿 → 留 30 分钟阅读 → 09:00 开盘

**核心逻辑：**
- 21:00~02:30 的新闻已反映在夜盘价格中 → **不重复分析**
- 只分析"价格还没反映"的信息 → 这才是简报的真正价值

## 第7页：LLM 分析与报告生成（2.5分钟）

**两步处理流水线**

**第一步：筛选（news_filter.md）**
```
91条原始新闻 → LLM 判断"是否与商品相关"
             → 保留 33 条
             → 剔除韩股、白酒、科技等无关新闻
```

**第二步：影响标注（impact_analyze.md）**
每条新闻标注：
- `impact_direction`: bullish / bearish / neutral / mixed
- `impact_strength`: high / medium / low
- `confidence`: high / medium / low
- `related_assets`: gold / silver / crude_oil / copper / usd_index
- `reason`: 分析依据（如"中东地缘风险上升+霍尔木兹海峡局势"）

**第三步：汇总输出**
- 按品种聚合 → 判断整体倾向（黄金26条→偏多，原油20条→偏多）
- 生成 Markdown 简报（10条最重要新闻）
- 生成 Excel（全部33条，14个结构化字段）

**Prompt 工程：** 只有2个专门的提示词文件，`impact_analyze.md` 支持注入回测校准规则（`{CALIBRATION_SECTION}` 占位符）

## 第10页：自我复盘与校准——亮点之二（1.5分钟）

回测数据积累后，自动检测偏差

**发现：**
- 原油整体准确率 25%，存在系统性高估
- 白银判断样本太少（1次），置信度不足

**校准闭环：**
```
回测 → 自我复盘 → 生成校准文本 → 注入 LLM prompt
                                       ↓
                                 下次分析时自动修正
```

**意义：** 传统统计回测只是看结果，我们的系统能做到 **LLM 自我修正**。

### 可能的问题

**Q：为什么不用 Bloomberg？**
→ 成本问题，我们的目标是用公开 API + LLM 实现低成本的个人工具。

**Q：LLM 分析准确吗？**
→ 我们有回测框架量化跟踪，持续校准；黄金判断准确率约 60%，原油在 25%~75% 波动。

**Q：能用于实盘吗？**
→ 不能，报告中明确标注"仅用于课程实验展示"。

**Q：每天跑一次的话，历史数据怎么积累？**
→ 每次运行先保存昨日快照到 `output/`，回测引擎读快照对比真实行情，`self_improve.py` 汇总全部历史记录分析偏差。
