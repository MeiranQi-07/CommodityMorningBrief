# 金银商品相关新闻筛选任务

请判断输入新闻是否与金银贵金属、大宗商品、原油或宏观市场有关。

保留以下类型新闻：

1. 黄金、白银、贵金属直接相关新闻；
2. 原油、天然气、铜、锡、镍、铝、锌、铅等工业金属及大宗商品新闻；
3. 美元指数、美债收益率、美联储、利率预期新闻；
4. 通胀、CPI、PPI、非农就业等宏观数据；
5. 地缘政治、战争、制裁、避险情绪相关新闻；
6. 央行购金、国际金价、COMEX、伦敦金、伦敦银、沪金、沪银相关新闻。
7. 能源、矿产、煤炭、铁矿石、农产品等相关新闻。

剔除以下新闻：

1. 普通个股公告；
2. 与商品无关的行业新闻；
3. 娱乐、体育、社会新闻；
4. 重复快讯；
5. 无法判断具体影响对象的噪声新闻。

输出字段：

{
  "keep": true,
  "category": "",
  "related_assets": [],
  "reason": ""
}
